# E-Learning Resources App

## Project Description

The **E-Learning Resources App** is a Flutter-based application developed to explore the practical implementation of Flutter widgets, layouts, navigation, state management, forms, and animations.

This project is developed step by step through experiments, starting with Dart basics and a basic Flutter application. Each experiment introduces concepts that help build a structured, interactive, and responsive user interface.

The project provides practical experience in Flutter application development and creates a foundation for developing more advanced educational applications.

## How to Run the Project

### Prerequisites

Install the following tools:

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Git

### Steps

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command to download dependencies:

```bash
flutter pub get
```

5. Run the application:

```bash
flutter run
```
