# E-Learning Resources

## Abstract

E-Learning Resources is a Flutter-based application developed to explore the practical implementation of Flutter widgets, layouts, navigation, state management, forms, and animations.

This project is developed step by step through experiments, starting with Dart basics and a basic Flutter application. Each experiment introduces concepts that help build a structured, interactive, and responsive user interface.

The project provides practical experience in Flutter application development and creates a foundation for developing more advanced educational applications.

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/gollapallybindhupriya-oss/e-learning-resources.git
```

### 2. Navigate to the Project Directory

```bash
cd e-learning-resources
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run -d chrome
```
